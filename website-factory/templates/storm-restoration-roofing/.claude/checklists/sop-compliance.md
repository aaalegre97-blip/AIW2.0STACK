# SOP Compliance Checklist — Storm-Restoration Roofing

Run this checklist against every client build before deployment.

## Voice + copy locks

- [ ] No em-dashes (—) anywhere in the final copy
- [ ] No banned phrases: leverage, synergize, robust, seamless, cutting-edge, game-changer, world-class, innovative, solutions provider, best in class, second to none
- [ ] CTAs use action verbs only (Schedule, Book, Get, Call, Text, Start, See, Meet)
- [ ] No "Learn more" / "Explore" / "Discover" / "Find out more" CTAs
- [ ] Section headers are UPPERCASE (using Oswald)
- [ ] Body sentences are short and direct

## Insurance-advocate language

- [ ] Hero mentions insurance-claim advocacy OR deductible-only pricing
- [ ] Insurance-advocate 3-step process is present above services
- [ ] Public adjuster language is present in either process or FAQ
- [ ] Insurance carrier logos or "we work with" language appears in trust bar or footer
- [ ] FAQ includes: "Will you handle my insurance?", "What if my claim is denied?"

## Trust stack

- [ ] Manufacturer certifications (GAF Master Elite / Owens Corning Platinum / CertainTeed SELECT) displayed
- [ ] State license number displayed with numeric value (not just "Licensed" badge)
- [ ] BBB A+ badge if applicable
- [ ] Google reviews aggregate ("4.9 ★ · XXX reviews") in hero and reviews section
- [ ] Photo/video testimonials from real customers

## Phone-first CTA

- [ ] Phone number visible in header at all screen sizes
- [ ] Click-to-call anchor on mobile
- [ ] StickyMobileBar (Call · Text · Book) present on all pages, mobile only
- [ ] Phone number appears at least 3 times on home page

## SEO

- [ ] Title tag follows pattern: "{City} Storm-Damage Roofers | {Company} — Free Inspection"
- [ ] Meta description mentions insurance + city + GAF Master Elite (if applicable)
- [ ] LocalBusiness / RoofingContractor schema markup present
- [ ] AggregateRating schema populated
- [ ] Service pages exist for each of the 4 core services

## Assets

- [ ] Client logo present at correct dimensions (SVG preferred)
- [ ] Hero image: drone shot of finished roof OR crew on roof (never damaged roof)
- [ ] Before/after photo gallery present with 4+ pairs
- [ ] Owner photo present in AboutOwner section

## Accessibility

- [ ] All interactive elements have adequate touch targets on mobile (44x44 min)
- [ ] Color contrast passes WCAG AA (accent red on primary black passes)
- [ ] Form fields have visible labels
- [ ] Prefers-reduced-motion respected for all reveal animations
